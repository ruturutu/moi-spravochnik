# Мой справочник — версия 1.0

Лёгкое веб-приложение/PWA для Android и Windows. Содержит проекты, дерево разделов и подразделов, заметки, визуальные карточки-переходы, изображения, внешние ссылки, поиск и экспорт резервной копии.

## Что уже работает
- Создание и удаление проектов.
- Создание разделов и вложенных подразделов.
- Дерево разделов проекта слева на широком экране.
- Карточки с изображениями или цветным оформлением.
- Заметки, описания и внешние ссылки.
- Поиск по справочнику.
- Автосохранение на устройстве.
- Экспорт/импорт резервной копии JSON.
- PWA-установка на Android и Windows.
- Облачная синхронизация через Supabase (нужен бесплатный аккаунт и однократная настройка).

## Важное о синхронизации
Локальное сохранение работает сразу. Для синхронизации между устройствами необходимо подключить собственный Supabase-проект:
1. Создайте проект на https://supabase.com.
2. Откройте SQL Editor и выполните содержимое `supabase_schema.sql`.
3. В Project Settings → API скопируйте Project URL и публичный `anon`/`publishable` key.
4. Разместите папку приложения на HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel).
5. Откройте приложение → Настройки → вставьте URL и ключ → «Подключить и войти».
6. Создайте аккаунт с email и паролем. На Android и Windows войдите в один и тот же аккаунт.

Не используйте `service_role` key в браузере. Только публичный anon/publishable key.
При включённом подтверждении email подтвердите адрес по письму.

## Запуск для проверки
Можно открыть `index.html` локально для проверки базовых функций, но установка PWA, Service Worker и облачная авторизация требуют HTTPS-хостинга (или localhost).

## Публикация через GitHub
Загрузите файлы в корень репозитория. В настройках репозитория откройте Settings → Pages, выберите Deploy from a branch → main → /(root) → Save. После публикации откройте выданный HTTPS-адрес.
